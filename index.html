No shared progression

Six games. Six brains.

GD-le keeps a guess board. Connections keeps mistakes. Thumbnaille keeps attempts. Higher / Lower keeps a run streak. Demon Order keeps a score. Songle keeps audio attempts. They share the level database and the visual language, but no win unlocks, modifies or resets another game. Daily answers are generated from the local date, so every player gets the same puzzle on the same day.

How GD Arcade works

Six independent daily games, one shared level database.

  1. 1Choose a cabinet. Every game has a daily puzzle and a practice mode. Daily answers are deterministic: the same date gives the same puzzle to everyone.
  2. 2No cross-game progression. Streaks, scores, mistakes, attempts and completion status are stored separately per game in your browser.
  3. 3Real data where possible. Levels come from GDBrowser, rankings from Pointercrate, thumbnails from levelthumbs.prevter.me and songs stream from Newgrounds.
  4. 4Missing data is labelled. If a thumbnail, stat or audio source is unavailable, the interface says so instead of inventing a value.

Accessibility: keyboard focus states, searchable comboboxes, arrow-button sorting, reduced-motion support and a settings panel are built in.
