Two ranking sources

Pointercrate uses exact ranked positions. In-game tiers uses one level from each official demon tier, so the order is unambiguous.

Daily always uses six Pointercrate-ranked demons. Practice and Endless let you choose.

Scoring

Each correctly placed demon scores 20 × its demon tier. A perfect ladder adds a 100-point bonus, then the round multiplier applies: Easy 1×, Normal 1.5×, Hard 2×.

How to play Demon Order

Sort the ladder from hardest at the top to easiest at the bottom.

  1. 1Drag rows into order, use the up/down buttons, or focus a row and press ↑ / ↓.
  2. 2Press Check order. Correct positions turn green, wrong positions turn red, and the true order is revealed underneath.
  3. 3Daily is one fixed six-demon Pointercrate ladder. Endless continues after a perfect ladder and ends on the first wrong check.
  4. 4Difficulty changes the ladder size and points multiplier. The ranking source is always shown above the board.

Source note: Pointercrate #1 is the hardest ranked demon. In-game tiers use the official Easy / Medium / Hard / Insane / Extreme Demon labels.
